# 📘 Assignment: Building REST APIs with FastAPI

## 🎯 Objective

Build a simple REST API in Python using FastAPI so you can practice creating endpoints, handling requests, and returning JSON responses.

## 📝 Tasks

### 🛠️ Create a Basic API

#### Description
Create a FastAPI application that exposes a simple endpoint and returns JSON data.

#### Requirements
Completed program should:

- Import `FastAPI` and create an app instance
- Define at least one `GET` route
- Return JSON data in a clear, readable format
- Run the app locally with `uvicorn`

### 🛠️ Add a Data-Driven Endpoint

#### Description
Extend the API so it can accept input and return a response based on a request.

#### Requirements
Completed program should:

- Define a route that accepts data from a request body or URL parameter
- Return a structured JSON response
- Include at least one example request and response
- Handle errors or missing values gracefully

### 🛠️ Stretch Goal: Multiple Routes

#### Description
Add more routes to make the API feel like a small real-world service.

#### Requirements
Completed program should:

- Include multiple endpoints for different actions
- Use descriptive route names and response data
- Keep the API organized and easy to follow
- Demonstrate how the app could be expanded in a future project
