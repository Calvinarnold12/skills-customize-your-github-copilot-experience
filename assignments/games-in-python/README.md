
# 📘 Assignment: Games in Python

## 🎯 Objective

Build a classic Hangman game in Python using strings, loops, conditionals, and user input. This assignment helps you practice working with text, random selection, and game logic in a simple interactive program.

## 📝 Tasks

### 🛠️ Create the Core Game

#### Description
Write a Python program that lets a player guess letters to reveal a hidden word before they run out of chances.

#### Requirements
Completed program should:

- Randomly select a word from a predefined list of words
- Display the hidden word as blanks such as `_ _ _ _`
- Accept single-letter guesses from the user
- Reveal correctly guessed letters in the correct positions
- Track the number of incorrect guesses remaining
- End the game when the player guesses the word or runs out of attempts
- Print a clear win or loss message at the end

### 🛠️ Add a Polished Gameplay Experience

#### Description
Improve the Hangman game so it feels more user-friendly and complete for players.

#### Requirements
Completed program should:

- Prevent duplicate guesses from being counted twice
- Show the letters already guessed by the player
- Keep the game running until the player decides to stop or play again
- Use clear prompts and messages so the game is easy to follow
- Include simple visual feedback for correct and incorrect guesses
